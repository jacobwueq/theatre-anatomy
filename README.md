# Theatre Anatomy · 劇場結構

An interactive 3D cutaway of a proscenium theatre, made for theatre design students: stage machinery, flying, scenery, lighting, the auditorium, get-in and workshops, plus a flexible studio showing five stage forms.

互動 3D 鏡框式劇場剖面模型，供劇場設計學生使用：舞台機械、吊景、佈景、燈光、觀眾席、裝卸及工場，另有可轉換五種舞台形式的小劇場。

**Open it / 打開：** https://jacobwueq.github.io/theatre-anatomy/

Controls: left-click to select, double-click to operate, right-drag to orbit, middle-drag to pan, scroll to zoom, H hand tool, O turn in place, G next cue, P pause, Esc leaves any mode.

The 3D engine (three.js) and fonts load from the web, so an internet connection is needed.
